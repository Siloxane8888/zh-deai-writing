# 精简版提示词

篇幅不够、或只想快速跑一遍时用这个。仍然不回传全文，只回补丁。

```
你是中文写作编辑。把下面的中文文章降 AI 痕迹。核心不是换词，是打破均匀度。只改文字，不改格式。

【输出方式】
不要重发全文。输出一个 JSON：

{"edits":[{"anchor":"该段开头 12–16 个唯一字","scope":"body","new_text":"该段改后的完整正文"}],
 "skipped":[{"anchor":"……","reason":"contains_field / contains_link / mixed_format"}],
 "selfcheck":{"para_cv_before":0,"para_cv_after":0,"sent_cv_before":0,"sent_cv_after":0,"equal_runs_before":0,"equal_runs_after":0,"modal_before":0,"modal_after":0,"unsolved":[]}}

【改什么】
1. 段落长度变异系数（CV=标准差÷均值）低于 0.25 就打散重排，目标 0.30–0.40；最长段与最短段字数比 ≥ 4；至少留 2 个 50 字以内的独立短段。
2. 句长 CV 目标 ≥ 0.45；全文必须同时有 10 字以内短句和 60 字以上长句。
3. 同段内连续 3 句字数完全相同，一律拆。
4. 每段都用"话题句+判断句"起笔的，改掉约三分之一，换成从具体动作或具体数字起笔。
5. 三项并列排比超过每 500 字 1 处就拆。
6. "可以/如果/若/先/再/最后/首先/其次/需要/适合"超过每 50 字 1 次，砍一半；不要用同义词轮换降频，直接删句换句型。
7. 搜出"需由作者/待补/本稿/根据实际记录"这类写给作者自己的话，删掉——那是生成时把提示词写进文章了。
8. 摘要和结尾的声明腔（"本文仅供/不构成/由……负责"）改成第一人称的具体交代。
9. 抽象表态换成具体动作：不写"这让我更明白重要性"，写"我在练习本上画两栏，左栏记什么、右栏记什么"。
10. 同段内若存在加粗/斜体混排，跳过不改。

【不许动】
- 不合并、不拆分段落。段落数必须和原文一致。
- 不改数字、单位、[1] 这类引用标记、代码、公式、链接、文献著录。
- 不编造原文没有的数字、经历、课程名、引用。
- 不把"可能"改成"确定"，不加假错字和口头禅，不用"说白了/真正重要的是"这类新套话。
- 含域代码、图片、超链接的段落跳过，写进 skipped。

【自检】
数据只放在 selfcheck 字段里。不要写进 new_text，不要在文档里生成任何"修改说明"。没解决的痕迹如实列进 unsolved，不要声称全部消除。

正文：
```

纯文本环境没有脚本时，仍按这个 JSON 回；人工按 anchor 找到段落、整段选中、用"只保留文本"方式粘贴。

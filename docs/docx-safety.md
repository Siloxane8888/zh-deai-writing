# 为什么"把文档重发一遍"会毁掉格式

## 现象

把一份 `.docx` 论文上传给 AI，让它"润色一下、去掉 AI 味"。AI 读得到正文，但它读不到你的样式表。它回你一份 Markdown 或者纯文本全文，你再"保存一份新的 Word"——于是：

- 所有标题变成普通段落，或者被降级成 1 级标题
- 目录变成一堆静态文字，或者直接消失
- 自动编号（1. 2. 3. / 一、二、三、）重新从 1 开始，或者变成手打的数字
- 页眉页脚的标题、页码全部重置
- 表格被拍平成文本，或者行列错位
- "表 1""图 1"这类交叉引用变成死文字，正文里改个顺序也不会跟着变
- 参考文献的悬挂缩进、DOI 超链接失效
- 图片位置错乱，题注和图片分离

这不是 AI 的失误。**.docx 不是一个文本文档，是一个压缩包里的关系图。** 文字只占其中一部分。

## 包里到底有什么

一个典型的论文 `.docx` 解压后：

```
word/document.xml        正文：段落 + run + 样式引用
word/styles.xml          样式表：标题、正文、题注、参考文献……的字号行距
word/numbering.xml       自动编号的定义
word/settings.xml        文档级设置
word/header*.xml         页眉（每节一份）
word/footer*.xml         页脚
word/media/*.png         图片
docProps/core.xml        作者、创建时间、修订次数
docProps/app.xml         页数、字数、累计编辑时长
```

正文里一个段落长这样：

```xml
<w:p>
  <w:pPr><w:pStyle w:val="a0"/><w:keepNext/><w:ind w:firstLine="420"/></w:pPr>
  <w:r><w:rPr><w:sz w:val="24"/></w:rPr><w:t>正文内容……</w:t></w:r>
</w:p>
```

`pPr` 管段落（样式、缩进、间距、编号），`rPr` 管字符（字体、字号、加粗）。**文字只在那一个 `<w:t>` 里。**

AI 回传全文，等于把 `pPr`、`rPr` 和其中所有的域代码全部丢掉，只留下 `<w:t>` 的内容。所以格式必然全毁——这不是提示词写得不够好，是信息在通道里被丢了。

## 正确做法：补丁，不是重发

把改动压缩成"哪一段改成什么"，让脚本在原文件上就地替换：

```
AI 输出：{anchor: "程序能跑出正确答案，不等于写他", new_text: "……"}
脚本执行：找到含这个 anchor 的段落 → 保留 pPr 和第一个 run 的 rPr → 只换文字
```

这样：

- 段落样式来自原文件，一个字没动
- 段落数和段落顺序不变，自动编号不会错位
- 目录域、页码域、表图交叉引用原样保留
- 表格、图片、页眉页脚完全不经过脚本
- 字数、页数会变（这是我们要的），但结构不变

`scripts/apply_edits.py` 就是做这件事的，并且会主动拒绝不安全的情况：

| 情况 | 处理 | 原因 |
|---|---|---|
| 段落含 `fldChar` / `instrText` | 跳过 | 域代码会断，重开文档变错误提示 |
| 段落含图片 / 脚注 / 批注 | 跳过 | 重建 run 会丢这些锚点 |
| 段落含超链接 | 跳过 | 超链接文本不在 `p.runs` 里，会重复 |
| 段落内有手打换行 / 制表位 | 跳过 | 会被压平 |
| 段内多种字符格式混排 | 由 fingerprint 报告 | 整段合并会抹掉段内强调 |
| anchor 命中多个段落 | 报错退出 | 定位不唯一，宁可不动 |

## 改完必须验

`scripts/docx_fingerprint.py` 会给两个文件各拍一张结构快照再比对：

```
python scripts/docx_fingerprint.py 原稿.docx 改后.docx
```

检查项：段落数、每段的样式名与 `pPr` 指纹、样式直方图、表格行列、图片数、域代码数、超链接数、节数与页眉页脚文字。

输出"结构一致"才通过。任何一项不匹配，都会指出是第几段、哪个属性变了。

## 两件脚本不管的事

1. **目录页码**。正文长度变了，目录里的页码会失准。域是脚本刻意不碰的，改完在 Word 里 `Ctrl+A` → `F9` 手动更新。
2. **封面占位符**。姓名、学号这类字段永远自己填。让 AI 代填等于给它一个编造的机会。
